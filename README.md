# TechVerse API

TechVerse API is the backend service for the TechVerse blogging platform.

## Tech Stack

- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Hibernate
- MySQL
- Spring Security
- JWT Authentication
- Maven
- Lombok
- ModelMapper
- Swagger/OpenAPI

## Features

- User Management
- Category Management
- Blog Posts
- Comments
- JWT Authentication
- Role Based Authorization
- Image Upload
- Pagination & Sorting
- Search API
- Swagger Documentation
